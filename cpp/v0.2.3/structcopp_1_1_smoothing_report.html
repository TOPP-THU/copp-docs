Detailed Description

Diagnostics recorded while constructing a fitted waypoint path.

Returned by Path::smoothing_report(); mirrors Rust copp::path::SmoothingReport. axes, segments, and interpolated_segments describe the final representation, while refinements, fitting_rows, and checked_intervals are cumulative work counters. None of these values is an optimality or run-time guarantee.
