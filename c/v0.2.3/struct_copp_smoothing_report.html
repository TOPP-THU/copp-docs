Detailed Description

Diagnostics recorded while constructing a tolerance-fitted waypoint path.

Obtain this report with copp_path_smoothing_report. axes, segments, and interpolated_segments describe the final representation, while refinements, fitting_rows, and checked_intervals are cumulative work counters. None of these values is an optimality or run-time guarantee. Both vectors are library-owned and must be released together with copp_smoothing_report_free.

This report type is currently unstable: its fields and layout may change as additional waypoint path-construction algorithms are introduced.
