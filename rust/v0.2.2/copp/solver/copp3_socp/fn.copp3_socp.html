Expand description

Strict COPP3-SOCP API for production use.

§Purpose

Use this entry when caller only needs a valid Topp3Profile and treats non-accepted solver statuses as hard failures.

§Contract

  • Internally calls copp3_socp_expert.
  • Returns Ok(Topp3Profile { .. }) iff options.is_allow(solution.status) is true.
  • Returns Err(CoppError::ClarabelSolverStatus(...)) when status is not accepted.

§Returns

Returns accepted COPP3 profile.

§Errors

Returns CoppError on model/solver failures and non-accepted solver status.

§Notes

For workflows requiring low-level diagnostics (status and raw Clarabel solution fields), prefer copp3_socp_expert.
